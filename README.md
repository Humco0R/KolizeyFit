# KolizeyFit - Frontend (форк, учебный проект)

> ⚠️ Учебный проект. Не является официальным приложением сети спортзалов
> «Колизей» (Красноярск) и не аффилирован с ней. Разработан в рамках учебного
> курса как концепт мобильного приложения. Все данные, товары и абонементы
> в приложении вымышлены и используются исключительно в демонстрационных целях.

Форк совместного командного проекта. Я разрабатывал фронтенд на Flutter,
над бэкендом работали другие участники команды.
Оригинальный репозиторий: [ezMaple/KolizeyFit](https://github.com/ezMaple/KolizeyFit)

Мобильное приложение-концепт для сети фитнес-клубов: просмотр и покупка абонементов,
поиск залов по точкам, личный кабинет пользователя.

## Возможности

- **Регистрация и авторизация** пользователя
- **Профиль пользователя** - личные данные, история
- **Каталог абонементов** - карточки товаров с описанием и ценой
- **Точки спортзалов** - список залов сети с адресами
- **Корзина** - добавление абонементов, оформление покупки

## Технологии

| Задача | Инструменты |
|---|---|
| Мобильное приложение | Flutter, Dart |
| Нативная интеграция (iOS/Android) | Swift, C++, CMake — автогенерируемый код платформенной части Flutter |

## Мой вклад

Разрабатывал клиентскую часть на Flutter/Dart: экраны регистрации, профиля,
каталога абонементов и корзины. Бэкенд и часть инфраструктуры — работа
других участников команды в рамках оригинального репозитория.
